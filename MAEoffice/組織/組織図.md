# MAE 組織図

> ステータス：【仮説】初期案。部門の分け方や名前は、オーナーとの議論で見直す。

```
取締役会（オーナー）
  │  最終意思決定・方針の承認
  │
CEO マギ
  │  経営全般の統括・オーナーとの窓口
  │
  ├─ 経営企画部 ............ 戦略・事業計画・市場調査・KPI
  ├─ 商品開発部 ............ 商品企画・素材・製造・品質
  ├─ ブランド・マーケティング部 ... ブランド・SNS・広告PR・撮影
  ├─ EC・販売部 ............ EC運営・販売チャネル・顧客対応
  ├─ 財務部 ................ 収益計画・資金・価格・会計
  └─ オペレーション・法務部 .. 仕入れ・在庫物流・法務・開業手続き
```

## 運営の考え方

- 創業期は、**すべての部門をマギが兼務する**。部門は「仕事の担当範囲を整理するための箱」として使う。
- 事業が大きくなったら、部門ごとにAIエージェントや人を配置することを検討する。
- 部門をまたぐ判断や優先順位はマギが決め、重要事項はオーナーの承認を得る。
